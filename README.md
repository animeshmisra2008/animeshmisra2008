## About Me

I'm a B.Tech CSE student at MIT-WPU who likes building things, automating repetitive tasks, and figuring out why something stopped working five minutes after it worked perfectly.

Currently learning and working with:

- Python
- C++
- JavaScript
- Node.js
- Git & GitHub
- GitHub Actions

I'm particularly interested in automation, software development, and projects that solve annoyingly specific problems.
